# Furniture AI Designer

Новая рабочая версия проекта на базе репозитория Furniture-CNC-All.

## Цель

Создать собственную систему проектирования корпусной мебели:

**эскиз / IFC / текст → AI → параметрическая 3D-модель → взрывная схема → деталировка → фурнитура → раскрой → CNC.**

## v0.1

Текущий прототип уже содержит:

- параметрический корпус шкафа;
- ширину, высоту, глубину и толщину;
- секции;
- вертикальные перегородки;
- съёмные полки;
- фасады;
- выбор материала;
- интерактивный 3D;
- изометрический и фронтальный вид;
- 3D-взрывную схему;
- список деталей;
- базовую проверку размеров;
- сохранение/загрузку проекта JSON.

## Архитектура следующих версий

1. Собственный параметрический мебельный движок.
2. Материалы и кромка по каждой стороне детали.
3. Фурнитура и технологические правила.
4. Автоматическая сверловка.
5. Проверка коллизий и технологических ошибок.
6. IFC import/export.
7. AI: эскиз/фото/текст → мебель.
8. Взрывная схема с нумерацией и BOM.
9. Деталировочные чертежи.
10. Раскрой и nesting.
11. DXF.
12. CNC-постпроцессоры.
13. PDF/Excel.
14. Визуализация мебели в интерьере.

## Принцип разработки

Не копировать закрытый код коммерческих систем. Использовать собственную архитектуру и открытые библиотеки с совместимыми лицензиями.

## Рабочее название

**Furniture AI Designer**

Репозиторий сохраняет историю исходного проекта Furniture-CNC-All, но приложение и продуктовая архитектура переводятся на новый проект.
