# Furniture AI Designer

## Текущий контур v1.0

Furniture AI Designer — система проектирования корпусной мебели:

**текст / изображение / IFC → AI → параметрическая 3D-модель → распознавание деталей → материалы и кромка → фурнитура и присадка → раскрой → PDF-карта раскроя.**

### Утверждённые блоки

- параметрическое проектирование корпусной мебели;
- AI-распознавание по тексту;
- AI-анализ эскиза/фотографии;
- импорт IFC и распознавание деталей;
- сохранение исходной IFC-геометрии;
- материалы и толщина;
- кромка по сторонам детали;
- фурнитура;
- автоматическая присадка и сверловка;
- проверка конструкционных конфликтов;
- 3D-модель и взрывная схема;
- деталировка;
- простой раскрой листового материала;
- **PDF-карта раскроя для производственника**.

## PDF-карта раскроя

Карта раскроя — это рабочий PDF-документ.

В неё входят:

- лист ЛДСП/МДФ/другого выбранного листового материала;
- размещение деталей на листе;
- номер и размеры каждой детали;
- материал и толщина;
- кромка по сторонам;
- присадка;
- сверловка;
- назначение отверстий и связанная фурнитура;
- отдельная схема присадки для каждой детали.

Координаты отверстий в PDF **выводятся** в минимальном виде: X и Y для каждой операции сверления/присадки.\n\nПрограмма не управляет конкретным станком: PDF передаётся производственнику, а настройка станка и дальнейшее производство выполняются вне Furniture AI Designer.

### В карту раскроя не входят

- Excel;
- G-code;
- CNC-постпроцессоры;
- DXF;
- режимы резания;
- инструменты станка;
- станочные программы;
- производственный паспорт;
- отдельный производственный пакет документов.

То есть карта раскроя остаётся одним понятным PDF-документом для человека на производстве.

## Принцип разработки

Не возвращать удалённые производственные/CNC-модули и не расширять карту раскроя лишней станочной логикой.

Развитие идёт только внутри утверждённого контура Furniture AI Designer.

## Контроль релиза

В репозитории есть автоматический release gate, который проверяет:

- AI;
- IFC;
- распознавание деталей;
- 3D;
- PDF-карту раскроя;
- присадку и сверловку;
- отсутствие запрещённых CNC/Excel-модулей;
- эталонные проекты.
